# FAULTLINE — The Room That Lies

A seated, hands-first mixed-reality puzzle. Use two hands to align a rift and an open palm to weld it shut.

Play in Quest Browser: https://mangroveuniversemu-bot.github.io/faultline-xr/

For desktop emulation, add `?emulator=1`. Select **Enter mixed reality** and then **Auto-play** to see scripted virtual hands run through the five rifts.

The 3D scene requires WebGL 2. If startup fails, try Quest Browser or a desktop browser with WebGL 2 enabled.
